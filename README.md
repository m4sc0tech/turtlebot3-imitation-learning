# Matías Silva
Computer Science student at Universidad Nacional Mayor de San Marcos.

### Current Project (2026)
**[TurtleBot3 Imitation Learning](https://github.com/m4sc0tech/turtlebot3-imitation-learning)**
Controlling a TurtleBot3 using a DS4 controller, built on ROS 2 Jazzy Jalisco and Ubuntu 24.04 (Noble Numbat) — now extending into imitation learning, training a model to replicate teleoperation behavior using LiDAR data and scikit-learn.

### Current Stack
